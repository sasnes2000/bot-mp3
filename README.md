# MP3 Bot — Русский / English for Cloudflare Pages

Версия с **выбором языка после `/start`**. Основана на последнем файле `_worker.js` с именами MP3 по названию YouTube-видео.

## Как выглядит выбор

`/start` → кнопки **🇷🇺 Русский** и **🇬🇧 English**. После нажатия бот сохраняет язык конкретного пользователя и отвечает на этом языке. Команда `/language` (или `/lang`) позволяет сменить язык. Переведены приветствие, сообщение об обработке, сообщение при неправильной ссылке и ошибка отправки MP3. Если выбор ещё не сделан, используется язык Telegram пользователя (`ru` → русский, другие → английский).

## Как обновить имеющийся проект

1. Распакуйте архив, загрузите обновлённый `_worker.js` в тот же GitHub-репозиторий Cloudflare Pages и сделайте Commit.
2. В Cloudflare откройте **Workers & Pages → ваш проект Pages → Settings → Bindings** (название раздела может немного отличаться).
3. Создайте **Workers KV namespace** с именем, например, `mp3-bot-languages` (в разделе **Storage & databases → KV**).
4. Добавьте к Pages-проекту **KV namespace binding**: **Variable name** `LANG_KV` (именно так, регистр важен), **KV namespace** `mp3-bot-languages`. Привязка нужна в окружении Production.
5. Сохраните изменения и сделайте **Redeploy** Production, чтобы привязка действовала в новой версии.
6. Откройте `https://bot-mp3.pages.dev/health`: в JSON должны быть `configured: true` и `language_storage: true`.
7. Отправьте `/start` в Telegram, нажмите нужный язык, отправьте текст или ссылку YouTube. Для изменения языка отправьте `/language`.

**Больше ничего менять не нужно:** существующий `TELEGRAM_BOT_TOKEN`, `SETUP_KEY`, адрес `/webhook` и регистрация webhook остаются прежними. Используется обычная reply keyboard, а не callback_query.

## Важные ограничения

- Для сохранения выбора языка **обязательна привязка KV `LANG_KV`**. Без неё бот сообщит о невозможности сохранить язык; по умолчанию останется язык клиента Telegram. Чтение KV может распространяться между дата-центрами с задержкой (eventual consistency).
- Изменение языка **не исправляет проблемы внешнего noTube**: MP3 может по-прежнему не скачиваться. Конвертация использует неофициальные endpoints `s47.notube.net`.
- Передавайте Telegram-токен только как Cloudflare Secret; не помещайте токен в исходный код или репозиторий.
- Загружайте только видео/аудио, для скачивания которых у вас есть права.
