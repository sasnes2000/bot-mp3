# YouTube -> Telegram MP3 (noTube, диагностический фикс)

Это обновление предыдущего тестового Pages-бота. Работает без VPS, но использует неофициальные, неподтвержденные методы noTube. Гарантии работы нет.

## Что исправлено
- Потоковая отправка файла в Telegram заменена на стандартный multipart FormData.
- Для безопасности памяти ограничение файла 20 МБ (для 3–5-минутных MP3 обычно достаточно).
- Проверка первых байт MP3 и логирование точной ошибки Telegram.
- Неэффективный fallback отправки приватной ссылки удален.

## Обновление
В репозитории GitHub `bot-mp3` замени только `_worker.js` файлом из архива. Подожди успешного Deploy в Cloudflare Pages. Секреты TELEGRAM_BOT_TOKEN и SETUP_KEY и webhook менять не нужно.

После запроса в Cloudflare Logs возможны сообщения:
- `MP3 bytes verified: ...` — файл реально скачан с noTube и прошел проверку заголовка.
- `Telegram MP3 upload failed: ...` — детальная ошибка загрузки в Telegram.
- `noTube MP3 HTTP ...` — noTube не дал файл.

Если 400 останется, скинь только ошибки логов; не присылай секреты, токены или полные HAR-файлы.

Без предварительного подтверждения права скачивания учитывай условия YouTube/noTube и авторское право.
