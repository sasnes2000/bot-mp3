# YouTube MP3 Telegram Bot — RU/EN — 40s/50MiB

Обновление для Cloudflare Pages. В этом архиве сохранены:
- выбор русского и английского языков (`LANG_KV`),
- название MP3 как у YouTube-видео,
- поддержка `noTube` и существующих webhook/секретов,
- проверка размера MP3 до 50 МиБ (но фактическая отправка больших файлов может упереться в память Cloudflare).

Изменено только время ожидания отдельных сетевых операций: скачивание MP3 с noTube и загрузка MP3 в Telegram — 40 секунд вместо 30 в предыдущей версии (или 18 в первоначальной версии RU/EN).

**Важно:** `ctx.waitUntil()` после быстрого ответа `/webhook` может продолжать работу максимум 30 секунд в Cloudflare. Это общий срок для конвертации, скачивания и отправки, и увеличенный `AbortSignal.timeout(40000)` **не отменяет лимит Cloudflare**. Если задача не успеет за 30 секунд, она может быть прервана без сообщения в Telegram. 40 секунд — предел таймаута конкретного `fetch` там, где выполнение ещё допускается, а не новая реальная общая длительность работы бота.

Если noTube возвращает HTML вместо MP3, изменение таймаута не помогает.

## Установка

1. В GitHub `bot-mp3` замените `_worker.js` файлом из архива.
2. Дождитесь успешного Production Deployment в Cloudflare Pages.
3. Проверьте ссылку в Telegram. Секреты и webhook заново подключать не нужно.

Для действительно надёжных задач дольше 30 секунд нужна иная архитектура — очередь с отдельным обработчиком или VPS, а не только изменение числа таймаута.
