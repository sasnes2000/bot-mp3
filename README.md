# Telegram YouTube → MP3 — Cloudflare Pages v2

**Внимание:** этот вариант использует сторонние бесплатные сервисы. Их доступность не гарантирована: автоматические скачивания могут блокироваться. Резервный API OmegaTech по документации умеет возвращать MP3 напрямую, но мы не смогли проверить его работу на реальном скачивании.

## Что изменено

- Вместо выдачи HTML-страницы сначала запрашивает MP3 напрямую через `api.omegatech.app/api/download/ytmp3?action=download`.
- Проверяет первые байты ответа, чтобы не пытаться отправлять HTML как аудиофайл.
- При ошибке пытается использовать прежний YTMP3.GE.
- Пишет в Cloudflare logs причину отказа каждого провайдера.

## Загрузка

### Если используешь GitHub Pages deployment (как сейчас)

1. На GitHub зайди в `sasnes2000/bot-mp3` → открой `_worker.js`.
2. Нажми карандаш (Edit this file), замени **всё содержимое** на `_worker.js` из архива v2.
3. Нажми `Commit changes`. Cloudflare Pages автоматически запустит новый deployment из GitHub.
4. Дождись зелёной галочки в Cloudflare Pages → Deployments → Production.
5. Бот должен сохранить существующий webhook и два Secret (`TELEGRAM_BOT_TOKEN`, `SETUP_KEY`) в Production — добавлять их повторно не нужно.
6. Отправь боту ссылку. Если снова ошибка — открой реалтайм-логи Pages: строка `Direct MP3 provider failed` подскажет причину.

### Если используешь Direct Upload

Загрузи содержимое ZIP как новый deployment в Cloudflare Pages. Не создавай второй бот и не публикуй секреты в файлах.

## Ограничения

Cloudflare `waitUntil()` выполняется лишь ограниченное время после ответа webhook (порядка 30 секунд). Если конвертация долгая, задачу может оборвать даже при работающем конвертере. Для длительных заданий потребуется внешний асинхронный сервис или очередь. Telegram принимает до 50 МБ при загрузке файла ботом.

Бот предназначен для видео, на которые у пользователя есть права на скачивание. Не размещай Telegram-токен или SETUP_KEY в публичном репозитории.
