# YouTube MP3 Telegram Bot — лимит 50 МБ / 50 MB

Изменена последняя версия бота с выбором **🇷🇺 Русский / 🇬🇧 English** и названиями файлов по заголовку YouTube. Лимит MP3 увеличен с 20 до **50 МиБ (52 428 800 байт)**.

## Обновление

1. В репозитории `bot-mp3` на GitHub замените старый файл `_worker.js` новым из этого архива.
2. Сделайте Commit и дождитесь успешного Production Deploy в Cloudflare Pages.
3. Токены, существующий webhook и KV binding `LANG_KV` оставьте без изменений.

## Важное ограничение

У Cloudflare Workers/Pages ограничение памяти **128 МБ на изолят**. Текущая отправка через `FormData` загружает весь MP3 в память, поэтому MP3 близкие к 50 МБ или несколько одновременных запросов могут закончиться ошибкой памяти или таймаутом, даже когда проверка размера пропускает файл. Это изменение устанавливает лимит в коде, но не увеличивает возможности Cloudflare и не исправляет нестабильный сервис noTube. Для надёжной отправки больших MP3 нужен отдельный сервер или иной потоковый сервис.

Скачивайте только контент, на который у вас есть права.


## Таймауты (версия 30 секунд)

Таймаут скачивания MP3 с noTube и таймаут загрузки MP3 в Telegram увеличены с 18 до 30 секунд каждый. Но Cloudflare Pages ограничивает время фоновой обработки после ответа вебхуку примерно 30 секундами **суммарно**, поэтому длинная конвертация всё ещё может прерываться; 30 + 30 секунд здесь не гарантируются. Лимит размера MP3 — 50 МиБ.
