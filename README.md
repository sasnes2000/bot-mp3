# Telegram YouTube → MP3 — версия с названием видео

## Что изменилось

Файл MP3 отправляется под названием исходного YouTube-видео (например, `Моя песня — Live.mp3`), а не `audio.mp3`. Название также передаётся Telegram как музыкальный заголовок.

Как определяется название:

1. Публичный YouTube oEmbed возвращает название ролика (API-ключ не нужен).
2. Если YouTube недоступен из Cloudflare, пробуем название из метаданных noTube.
3. Если оба источника не вернули название, используем `YouTube MP3.mp3`.

Запрещённые для имён файлов символы (`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`) заменяются пробелами; очень длинные названия обрезаются. Кириллица сохраняется.

## Обновление в Cloudflare Pages

В GitHub-репозитории `bot-mp3` замени **только** файл `_worker.js` новым из этого архива. Дождись успешного Production Deploy. Секреты и webhook не меняются.

## Важно

Эта версия исправляет **имя файла**, а не работоспособность noTube. Пока noTube/Telegram отклоняет скачивание, MP3 не будет отправляться. Без успешного получения MP3 название файла не влияет на ошибку конвертации. Тесты выполнены на имитированных ответах сервисов, не на живом скачивании YouTube.
